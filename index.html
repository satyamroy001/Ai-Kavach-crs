Offline Diff

This application performs the comparison entirely inside your browser. No text is transmitted to a server.

  • Paste text/code into both panels.
  • Or drag files directly onto either editor.
  • Press Compare or Ctrl + Enter.
  • Use Side-by-Side for visual comparison.
  • Use Unified for a traditional patch-style diff.
  • Download Diff creates a local text file.
